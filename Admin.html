Вход в админку

Введите пароль, созданный при первичной настройке Google Таблицы. Он хранится только в памяти этой вкладки.

Контент

Заголовок и адрес автоматически уменьшаются в фиксированных контейнерах. Переносы строк можно задать клавишей Enter.

Шрифт должен быть уже подключён на странице Tilda.

Ссылки и изображения

Используйте только HTTPS-ссылки. Для GitHub подходят GitHub Pages или jsDelivr; raw.githubusercontent.com для JS использовать не нужно.
